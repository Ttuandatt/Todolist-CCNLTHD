# 📘 REPORT STYLE GUIDELINE — BACKEND SYSTEM (NestJS)

## 🎯 1. MỤC TIÊU

Tài liệu này quy định cách viết báo cáo kỹ thuật cho hệ thống backend NestJS.

Report phải là:
- ✅ System-level explanation
- ✅ Gắn với project thực tế
- ✅ Dễ hiểu cho beginner
- ✅ Thể hiện tư duy engineering

## 🧠 2. CORE PRINCIPLE

Mỗi section phải trả lời được:
“Hệ thống đang hoạt động như thế nào và tại sao lại thiết kế như vậy?”

## 🧱 3. PARAGRAPH STRUCTURE

Purpose → Context → Flow → Impact

## ❌ KHÔNG ĐƯỢC VIẾT

- WHAT / WHY / HOW / RESULT dạng checklist
- Lý thuyết chung chung
- Code không có context

## ✅ NÊN VIẾT

- Gắn với hệ thống thật
- Giải thích WHY
- Dùng transition tự nhiên

## 🔄 FLOW WRITING

Viết narrative, không liệt kê step

## 📊 DIAGRAM RULE

[Diagram: Name]
Components:
- ...
Flow:
A → B → C

## 🎓 CHECKLIST

- Có purpose?
- Có context?
- Có flow?
- Có impact?
